# Video-Streaming

Chill Stream is a video streaming platform where users can enjoy videos.<br>
A user can upload, update and delete there videos.<br>
Users can also enjoy videos uploaded by other users and can also react on that videos through likes, dislikes and comments.<br>
If a user likes videos uploaded by a particular user. The person can follow the creator and enjoy latest uploaded videos by the creator.
